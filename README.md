### How I ship this

I run an AI-augmented contribution pipeline built on Claude Code: scout unclaimed, well-scoped issues across active repos → cold-start implementer agent reproduces and fixes with tests → independent reviewer agent checks the diff → CI gates the merge. Every PR is human-reviewed before it goes out, and the entire ledger of merged/open PRs, repo health checks, and decisions to *not* pursue a repo is tracked and auditable — I don't just claim a number, I can show the receipts behind it.
